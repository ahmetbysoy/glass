# GlassPro

Kripto likidasyon takip ve tahmin uygulaması. Binance, OKX, Bybit, Bitget, Hyperliquid, Gate Futures verilerini gerçek zamanlı çekerek analiz eder.

## Kurulum
```bash
cp .env.example .env
./gradlew assembleRelease
```

## Özellikler
- Canlı likidasyon akışı
- Piyasa analiz motoru
- Çarpışma raporu (crash handler)
- Widget ve bildirim desteği (planlanıyor)
